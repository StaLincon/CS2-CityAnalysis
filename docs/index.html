🏙️ 都市天际线 II · 城市数据分析在线报告生成器

上传 Mod 导出的城市数据 → 填入 API Key → 浏览器内调用 AI 生成《政府工作报告》→ 在线预览 / 下载 Word。 全部在浏览器内运行，数据不上传任何服务器。

① 上传数据

支持 Mod 导出的 history.json（时间序列）、current_snapshot.json（当前快照）、full_history.json（完整历史），可多选。也可直接加载示例数据体验。

② 配置 AI 接口

采用标准 OpenAI 兼容协议。最省事：把「服务商」选成 SiliconFlow（硅基流动）——它浏览器直连免代理（返回 Access-Control-Allow-Origin: *），粘贴对应 Key 即可，无需部署任何东西，且可直接选用 DeepSeek 系列模型。DeepSeek 直连现在也已支持 CORS，但若你是双击本地文件(file://)打开本页，个别浏览器仍可能拦截，此时改用 SiliconFlow 或把页面部署到 GitHub Pages / 用本地服务打开即可。

🔒
隐私保障：你填写的 API Key 仅保存在本浏览器内存中，只会发往你填写的 AI 接口地址（如 DeepSeek / OpenAI），绝不会上传到任何第三方服务器；本应用不含任何数据统计或遥测，城市数据也仅在本地解析、仅随请求发往你选择的模型。
⚠️ 若填写 CORS 代理，请求（含 Key）将经过该代理服务器，请仅使用你自建或完全信任的代理。
