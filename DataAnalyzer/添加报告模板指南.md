# 添加报告模板指南

本文档详细说明如何在 DataAnalyzer 项目中添加新的报告模板类型。

## 一、报告生成总体架构

### 第五步：创建章节生成方法

**文件**: `Services/LlmService.cs` 或 `Services/BaseApiService.cs`

```csharp
private async Task<List<ReportChapter>> GenerateYourTemplateChapters(
    YourReport report, string ctx, string cityName,
    IProgress<(string chapterId, string title, int current, int total)> progress)
{
    var chapters = new List<ReportChapter>();
    
    // 定义报告章节结构
    var defs = new List<(string id, string title, Func<string, string> promptFn)>
    {
        ("opening", "第一章 总论", c => YourTemplatePrompts.GetOpeningPrompt(cityName, c)),
        ("chapter1", "第二章 XXX", YourTemplatePrompts.GetChapter1Prompt),
        ("chapter2", "第三章 XXX", YourTemplatePrompts.GetChapter2Prompt),
        // 添加更多章节...
    };

    for (int i = 0; i < defs.Count; i++)
    {
        var (id, title, promptFn) = defs[i];
        progress?.Report((id, title, i + 1, defs.Count));
        
        var prompt = promptFn(ctx);
        var content = await SendAsync(YourTemplatePrompts.SystemPrompt, prompt);
        chapters.Add(new ReportChapter { Id = id, Title = title, Content = content });
    }

    return chapters;
}
```

### 第七步：创建Word文档生成器

**文件**: `Services/YourTemplateReportGenerator.cs`

```csharp
using System;
using System.Collections.Generic;
using System.IO;
using DataAnalyzer.Models;
using DocumentFormat.OpenXml.Packaging;
using DocumentFormat.OpenXml.Wordprocessing;
using static DataAnalyzer.Services.ReportLayoutHelper;

namespace DataAnalyzer.Services
{
    public class YourTemplateReportGenerator
    {
        private readonly List<ReportChapter> m_Chapters;
        private readonly YourReport m_Report;
        // ... 其他成员变量

        public void Generate()
        {
            using var doc = WordprocessingDocument.Create(m_OutputPath, WordprocessingDocumentType.Document);
            var mainPart = doc.AddMainDocumentPart();
            mainPart.Document = new Document();
            var body = mainPart.Document.AppendChild(new Body());

            // 页脚
            var footerPart = mainPart.AddNewPart<FooterPart>();
            footerPart.Footer = CreatePageNumberFooter();
            var footerId = mainPart.GetIdOfPart(footerPart);

            // 页面设置（GB/T 9704-2012）
            body.AppendChild(CreatePageSettings(null, footerId));

            // 版头
            BuildDocumentHeader(body, m_CityName);

            // 标题
            body.AppendChild(CreateDocumentTitle("关于XXX的报告"));

            // 主送机关
            body.AppendChild(CreateAddressee("XXX："));

            // 内容章节
            foreach (var chapter in m_Chapters)
            {
                BuildChapter(body, chapter);
            }

            // 版记
            BuildDocumentFooter(body);

            mainPart.Document.Save();
        }

        private void BuildChapter(Body body, ReportChapter chapter)
        {
            // 使用 ReportLayoutHelper 的方法构建章节
            // 一级标题
            body.AppendChild(CreateHeading1(chapter.Title));
            
            // 正文
            body.AppendChild(CreateBodyParagraph(chapter.Content));
        }
    }
}
```

private ReportTemplate GetSelectedTemplate()
{
    if (CmbReportTemplate.SelectedItem is ComboBoxItem item && item.Tag is string tag)
    {
        return tag switch
        {
            "Development" => ReportTemplate.Development,
            "YourNewTemplate" => ReportTemplate.YourNewTemplate,
            _ => ReportTemplate.Development
        };
    }
    return ReportTemplate.Development;
}

### 第九步：更新生成逻辑

**文件**: `MainWindow.xaml.cs`

在 `BtnPreview_Click` 和 `BtnGenerate_Click` 方法中添加模板判断：

```csharp
private void BtnPreview_Click(object sender, RoutedEventArgs e)
{
    var template = GetSelectedTemplate();
    
    // ... 现有代码 ...
    
    // 添加新模板的处理分支
    switch (template)
    {
        case ReportTemplate.Development:
            var devReport = engine.AnalyzeDevelopment();
            if (devReport != null)
            {
                var gen = new DevelopmentReportGenerator(new List<ReportChapter>(), devReport, ...);
                gen.Generate();
            }
            break;
            
        case ReportTemplate.YourNewTemplate:
            var yourReport = engine.AnalyzeYourTemplate();
            if (yourReport != null)
            {
                var gen = new YourTemplateReportGenerator(new List<ReportChapter>(), yourReport, ...);
                gen.Generate();
            }
            break;
    }
}
```

## 四、ReportLayoutHelper 使用指南

`ReportLayoutHelper` 提供了符合 GB/T 9704-2012《党政机关公文格式》的布局方法：

### 常用方法

| 方法 | 用途 |
|------|------|
| `CreatePageSettings(headerId, footerId)` | 创建页面设置（A4、页边距等） |
| `CreateDocumentHeader(cityName)` | 创建版头（发文机关标志、发文字号、红色分隔线） |
| `CreateDocumentTitle(title)` | 创建公文标题 |
| `CreateAddressee(text)` | 创建主送机关 |
| `CreateHeading1(text)` | 一级标题（黑体） |
| `CreateHeading2(text)` | 二级标题（楷体） |
| `CreateBodyParagraph(text)` | 正文段落（仿宋3号，28磅行距） |
| `CreateTable(rows, cols)` | 创建表格 |
| `CreateTableCell(text, isHeader)` | 创建表格单元格 |
| `BuildDocumentFooter(body)` | 创建版记 |
| `CreatePageNumberFooter()` | 创建页脚（页码） |

### 正文样式说明

根据 GB/T 9704-2012：
- **字体**: 3号仿宋体
- **行距**: 固定值28磅
- **每行**: 28个字
- **每面**: 22行

## 六、注意事项

1. **线程安全**: AI生成是异步操作，确保UI更新在主线程
2. **错误处理**: 为每个步骤添加异常捕获和日志
3. **进度反馈**: 使用 `IProgress<T>` 报告生成进度
4. **文件路径**: 使用 `Environment.CurrentDirectory` 确保路径正确
5. **资源释放**: Word文档使用 `using` 语句确保正确释放
